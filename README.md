# ProjetoFinalPOO1
Projeto Final – Sistema Orientado a Objetos em C# (Tema Livre)

Objetivo
Desenvolver um sistema completo em C#, com tema livre, aplicando os conceitos fundamentais da
Programação Orientada a Objetos. O projeto deve demonstrar domínio técnico e capacidade de
modelagem orientada a objetos.

Orientações Gerais
• O grupo escolherá livremente o tema do sistema (ex: controle de estoque, sistema de reservas, gerenciamento de pets, biblioteca, etc.).
• O foco principal é a correta aplicação dos conceitos de POO em C#.

Requisitos Obrigatórios

Lógica de Programação
• Uso de estruturas condicionais (if, switch) para controle de decisões.
• Uso de estruturas de repetição (for, while, foreach) para manipulação de dados.Encapsulamento com Restrições
• Atributos privados com acesso controlado por propriedades (get/set).
• Obrigatório aplicar restrições no set sempre que necessário, como validação de dados (ex: impedir idade negativa, limitar valores, validar formatos).

Construtores
• Utilização de métodos construtores para inicialização de objetos com dados obrigatórios.

Relacionamentos entre Classes
• Implementar herança obrigatoriamente (ex: classe base Pessoa, subclasses Cliente, Funcionario).
• Além da herança, o projeto deve conter pelo menos um dos seguintes tipos de relacionamento:
• Associação: uma classe utiliza outra sem dependência forte.
• Agregação: uma classe contém outra, mas ambas podem existir separadamente.
• Composição: uma classe contém outra de forma inseparável (vida útil dependente).

Polimorfismo
• Aplicação de polimorfismo por meio de sobrescrita de métodos ou uso de interfaces.

Tratamento de Exceções
• Uso de try, catch, finally para capturar e tratar erros de forma segura e informativa.

Entrega
Cada grupo deverá entregar:
• Código-fonte completo e funcional.
• Documento explicativo contendo:
• Tema escolhido e justificativa.
• Diagrama de classes com os relacionamentos.
• Descrição de como cada requisito foi implementado.
• Apresentação final demonstrando o funcionamento do sistema.
